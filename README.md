## 这本书讲什么

从"光学零基础、有 Python/NumPy 工程背景"起步，到能**独立理解并实现** die-to-database 检测所需的光学参考图渲染仿真算法。

- 📐 **四篇十九章 + 七个附录**，从复数与波动、傅里叶分析、衍射理论一路推到 Abbe/Hopkins 成像引擎
- ⚙️ **仿真模块化主线**：版图栅格化 → Abbe 源点引擎 → Hopkins/TCC 快速引擎 → 厚掩模 FDTD/RCWA → 参考图渲染与设备标定
- 🔍 **应用闭环**：die-to-database 检测全流程（配准/差分/判定/POD）与工程化实战
- 💻 可运行的 Python/NumPy 数值实验（附录 F 十个动手实验、附录 E 搭建 Mini-D2DB）
- 📖 面向零基础：每章 学习目标 → 推导（逐步中间步骤）→ 小结 → 习题
