第 2 章 复数与波动的数学

本章学习目标
  • 熟练进行复数运算，理解复数作为"振幅 + 相位"载体的意义；
  • 掌握欧拉公式与复指数表示的简谐波；
  • 理解相位差、光程差的概念与计算；
  • 会用复数方法处理波的叠加（干涉的数学雏形）。

2.1 为什么光学需要复数

光是一种波动，而描述波动最自然的数学语言是复指数函数。原因很简单：波的基本行为是"相位随传播累积"，而复数乘法恰好就是"模相乘、辐角相加"。用复数表示波之后，透镜的相位延迟、光瞳的滤波、衍射的传播，全都变成简单的乘法。可以说复数是光学的母语；本章把这门语言学扎实，后面所有章节都会轻松许多。

2.2 复数回顾

复数 \(z = a + bi\)（其中 \(i^2 = -1\)）由实部 \(a = \mathrm{Re}\,z\) 和虚部 \(b = \mathrm{Im}\,z\) 构成。把它画在复平面上：横轴实部、纵轴虚部，复数就是平面上的一个点或向量。

由此得到复数的两种等价写法。代数式 \(z = a + bi\)，与极坐标式（指数式）

$$ z = r\,(\cos\varphi + i\sin\varphi) = r\,e^{i\varphi},\qquad r = |z| = \sqrt{a^2+b^2},\qquad \tan\varphi = \frac{b}{a} $$

极坐标式的两个量在光学中各有专名：\(r\) 是模（振幅），\(\varphi\) 是辐角（相位）。

2.2.1 复数运算规则（务必熟练）

运算代数式指数式几何意义
加法\((a+bi)+(c+di)=(a+c)+(b+d)i\)—向量相加（平行四边形法则）
乘法交叉相乘合并\(r_1e^{i\varphi_1}\cdot r_2e^{i\varphi_2}=r_1r_2\,e^{i(\varphi_1+\varphi_2)}\)模相乘，辐角相加
共轭\(z^* = a-bi\)\((re^{i\varphi})^* = re^{-i\varphi}\)关于实轴镜像
模方\(|z|^2 = a^2+b^2\)\(zz^* = r^2\)向量长度的平方
除法分子分母同乘分母共轭\(\frac{r_1e^{i\varphi_1}}{r_2e^{i\varphi_2}} = \frac{r_1}{r_2}e^{i(\varphi_1-\varphi_2)}\)模相除，辐角相减

几个高频使用的恒等式：

$$ |z_1z_2| = |z_1||z_2|,\qquad |z^*| = |z|,\qquad z + z^* = 2\,\mathrm{Re}\,z,\qquad \mathrm{Re}\{z_1z_2^*\} = \text{两向量点积的 } r_1 r_2 \text{ 倍} $$

2.2.2 欧拉公式

联系两种表示的核心是欧拉公式（可由 \(e^x\)、\(\sin\)、\(\cos\) 的泰勒级数直接比较得到）：

$$ e^{i\varphi} = \cos\varphi + i\sin\varphi,\qquad e^{-i\varphi} = \cos\varphi - i\sin\varphi $$

两式相加/相减立即得到：

$$ \cos\varphi = \frac{e^{i\varphi}+e^{-i\varphi}}{2},\qquad \sin\varphi = \frac{e^{i\varphi}-e^{-i\varphi}}{2i} $$

特别地，\(e^{i\pi} = -1\)，\(e^{i\pi/2} = i\)，\(e^{i2\pi}=1\)。相位每增加 \(2\pi\)，复数转一整圈回到原位——这就是"相位以 \(2\pi\) 为周期"的原因。

例题 2-1　计算 \((1+i)^4\)。
解：\(1+i = \sqrt{2}\,e^{i\pi/4}\)，故 \((1+i)^4 = (\sqrt{2})^4 e^{i\pi} = 4\times(-1) = -4\)。用代数式逐次平方可验证：\((1+i)^2 = 2i\)，\((2i)^2 = -4\)。

2.3 简谐振动与波的描述

取一根弦上的一点，它随时间做简谐振动：位移 \(u(t) = A\cos(\omega t + \varphi_0)\)。这里 \(A\) 是振幅，\(\omega = 2\pi\nu\) 是角频率（rad/s），\(\nu\) 是频率（Hz），\(\varphi_0\) 是初相位。周期 \(T = 2\pi/\omega = 1/\nu\)。

波 = 振动在空间中的传播。沿 \(x\) 方向传播的平面简谐波：

$$ u(x,t) = A\cos(kx - \omega t + \varphi_0) $$
  • \(k = 2\pi/\lambda\) 称为波数（rad/m），\(\lambda\) 是波长：空间中相位差 \(2\pi\) 的两点相距一个波长；
  • 等相位面 \(kx-\omega t+\varphi_0 = \text{const}\) 以速度 \(v = \omega/k = \lambda\nu\) 向 \(+x\) 方向移动，\(v\) 就是波的相速度；
  • 固定时间看（\(t\) 不变）：\(u\) 是空间的余弦条纹；固定位置看（\(x\) 不变）：\(u\) 是时间的余弦振荡。

2.4 复数表示的波：复振幅的引入

对单色波（\(\omega\) 固定），实数表达式里的三角函数运算非常繁琐。利用欧拉公式，把余弦写成复指数的实部：

$$ u(x,t) = A\cos(kx-\omega t+\varphi_0) = \mathrm{Re}\Big\{ A\,e^{i(kx-\omega t+\varphi_0)} \Big\} = \mathrm{Re}\Big\{ \underbrace{A\,e^{i(kx+\varphi_0)}}_{\text{复振幅 } \tilde{u}(x)}\; e^{-i\omega t} \Big\} $$

关键观察：时间因子 \(e^{-i\omega t}\} 对单色波处处相同，与它相比，不同位置、不同路径的波只在空间因子 \(Ae^{i(kx+\varphi_0)}\) 上有差别。于是干脆丢掉时间因子，只用空间复数携带信息：

复振幅（complex amplitude）： $$ \tilde{u}(x,y,z) = A(x,y,z)\,e^{i\varphi(x,y,z)} $$ 模 \(A\) 描述各点振动的强弱，辐角 \(\varphi\) 描述各点振动的相位。整个波动光学（衍射、干涉、成像）都在复振幅层面进行，最后一步才转换成可测量的光强。

举例：振幅 2、相位 \(\pi/3\) 的波写作 \(\tilde u = 2e^{i\pi/3} = 1 + \sqrt{3}\,i\)。若它再经过一段路径使相位增加 \(\Delta\varphi\)、振幅衰减为原来的 \(T\) 倍，则新复振幅为 \(T\,\tilde u\, e^{i\Delta\varphi}\)——一次乘法完成。

2.4.1 相位与光程

光在折射率为 \(n\) 的介质中传播距离 \(s\)，相位累积为

$$ \Delta\varphi = k\,n\,s = \frac{2\pi}{\lambda}\,\underbrace{(ns)}_{\text{光程 OPD}} $$

其中 \(\lambda\) 为真空波长，\(ns\) 称为光程（optical path length）。相位由光程决定，而不是几何路程——这是第 6 章薄膜干涉和相移掩模的直接基础。

符号约定警告：本书采用 \(e^{-i\omega t}\) 时间约定，此时平面波空间因子为 \(e^{+i\mathbf{k}\cdot\mathbf{r}}\)，"相位超前"对应辐角变大。有的教材采用 \(e^{+i\omega t}\)，则符号全部反号。在一套代码里混用两种约定是初学者最隐蔽的错误来源：单独看每个公式都"能跑"，但组合起来传播方向或离焦符号就是反的。写仿真前先固定约定并在代码注释中声明。

2.5 用复振幅处理波的叠加

两列同频率的波在某点相遇，各自的复振幅为 \(\tilde u_1 = A_1e^{i\varphi_1}\)、\(\tilde u_2 = A_2e^{i\varphi_2}\)。真实的瞬时场是

$$ u(t) = \mathrm{Re}\{(\tilde u_1 + \tilde u_2)e^{-i\omega t}\} = A\cos(\omega t - \Phi) $$

即合成波仍是同频简谐波，其复振幅就是复振幅的直接相加 \(\tilde u = \tilde u_1 + \tilde u_2\)。用相量图（复平面上的向量加法）计算最直观：

$$ A^2 = |\tilde u_1 + \tilde u_2|^2 = A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2-\varphi_1) $$

合成强度不等于两波强度之和，多出的交叉项 \(2A_1A_2\cos\Delta\varphi\) 就是干涉项：

  • \(\Delta\varphi = 2m\pi\)（同相）：\(A = A_1+A_2\)，相长干涉；
  • \(\Delta\varphi = (2m+1)\pi\)（反相）：\(A = |A_1-A_2|\)，相消干涉；
  • 等振幅时 \(A=2A_1\cos(\Delta\varphi/2)\)，强度在 \(0\) 与 \(4A_1^2\) 之间变化。
例题 2-2　三束等幅光 \(\tilde u_m = A_0e^{im\delta}\)（\(m=0,1,2\)，相邻相位差 \(\delta\)）叠加，求合成强度。
解：这是三光束干涉（第 7 章光栅衍射的原型）。 $$ \tilde u = A_0(1 + e^{i\delta} + e^{i2\delta}) = A_0\,e^{i\delta}\frac{\sin(3\delta/2)}{\sin(\delta/2)},\qquad I = A_0^2\left[\frac{\sin(3\delta/2)}{\sin(\delta/2)}\right]^2 $$ 当 \(\delta = 2\pi/3\) 时三项之和为零——三束光可以完全相消。这正是相移掩模（第 12 章）利用的原理之一。

2.6 光强：从复振幅到可观测量

光的频率约 \(10^{14}\) Hz，没有任何探测器能直接跟踪如此快的振荡，所有探测器（眼睛、光电二极管、检测机相机）响应的都是能量的时间平均。定义光强：

$$ I = \langle u^2(t)\rangle_t = \frac{1}{2}A^2 \;\propto\; |\tilde u|^2 = \tilde u\,\tilde u^* $$

仿真的输出永远是光强；从复振幅到光强这一步是"取模方"，实部和虚部都参与：

$$ |\tilde u|^2 = (\mathrm{Re}\,\tilde u)^2 + (\mathrm{Im}\,\tilde u)^2 $$
常见错误：把 \(\mathrm{Re}\,\tilde u\)、\(\tilde u\)、\(|\tilde u|\)、\(|\tilde u|^2\) 混为一谈。正确关系链：实瞬时场 = \(\mathrm{Re}\{\tilde u e^{-i\omega t}\}\)；复振幅 = \(\tilde u\)；振幅 = \(|\tilde u|\)；光强 = \(|\tilde u|^2\)。差一个平方，边缘位置、对比度结论全错。

2.7 本章小结

  • 复数 \(re^{i\varphi}\)：模管大小、辐角管角度；乘法 = 模相乘、辐角相加。
  • 复振幅 \(\tilde u = Ae^{i\varphi}\) 是单色波的空间完整描述；探测器测量 \(|\tilde u|^2\)。
  • 相位累积 = \(2\pi \times\) 光程/\(\lambda\)；光程 = \(n \times\) 几何路程。
  • 波的叠加 = 复振幅相加；干涉项 \(2A_1A_2\cos\Delta\varphi\) 是所有成像反差的来源。
